# Contributing

## Setup

1. Utworz venv i aktywuj.
2. Zainstaluj requirements.txt oraz requirements-dev.txt.
3. Uruchom testy poleceniem pytest.

## Zasady zmian

- Zmiany powinny przechodzic testy jednostkowe i integracyjne.
- Nie commituj lokalnych baz danych i artefaktow analiz.
- Przy zmianach w logice analizy aktualizuj README.

## Pull request

- Opisz kontekst i cel zmiany.
- Dodaj kroki reprodukcji i walidacji.
- Przy zmianach w PDF dodaj opis zachowania paginacji.
